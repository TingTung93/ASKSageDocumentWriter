# Local OpenAI Provider Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a browser-side Local OpenAI-compatible provider for Ollama, llama.cpp, LM Studio, and custom `/v1` endpoints while keeping OpenAI tool calls as the canonical app-wide tool format.

**Architecture:** Extract provider-neutral OpenAI-compatible request/response mapping from `OpenRouterClient`, then add `LocalOpenAIClient` as a thin adapter with optional auth, local endpoint diagnostics, and local model capability enrichment. Provider selection remains in `useAuth`; UI changes add Local OpenAI presets, privacy warnings, model recommendations, and probe results without changing Ask Sage or OpenRouter behavior.

**Tech Stack:** React 18, TypeScript, Vite, Zustand, Vitest, React Testing Library, existing `LLMClient` provider abstraction.

```ts
import { AskSageError } from '../asksage/types';
import type {
  ModelCapabilities,
  ModelInfo,
  OpenAITool,
  OpenAIToolCall,
  OpenAIToolChoice,
  QueryInput,
  QueryResponse,
  QueryUsage,
} from '../asksage/types';

export interface OpenAIModelRow {
  id: string;
  name?: string;
  created?: number | string;
  pricing?: { prompt?: string; completion?: string; request?: string; image?: string };
  context_length?: number;
  architecture?: {
    modality?: string;
    input_modalities?: string[];
    output_modalities?: string[];
    tokenizer?: string;
  };
  supported_parameters?: string[];
}

export interface OpenAIChatMessage {
  role: 'system' | 'user' | 'assistant' | 'tool';
  content: string;
  tool_calls?: OpenAIToolCall[];
  tool_call_id?: string;
  name?: string;
}

export interface OpenAIChatBody {
  model: string;
  messages: OpenAIChatMessage[];
  temperature?: number;
  tools?: OpenAITool[];
  tool_choice?: 'none' | 'auto' | 'required' | OpenAIToolChoice;
  plugins?: Array<{ id: 'web'; max_results?: number }>;
}

export interface OpenAIChatCompletionResponse {
  id: string;
  object?: string;
  choices: Array<{
    index?: number;
    message: {
      role: string;
      content?: string | null;
      tool_calls?: OpenAIToolCall[];
    };
    finish_reason?: string;
  }>;
  usage?: {
    prompt_tokens?: number;
    completion_tokens?: number;
    total_tokens?: number;
    [key: string]: unknown;
  };
}

export interface OpenAIEmbeddingsResponse {
  data: Array<{ index: number; embedding: number[] }>;
  usage?: { prompt_tokens?: number; total_tokens?: number };
}

export function urlForOpenAIPath(baseUrl: string, path: string): string {
  const trimmed = baseUrl.replace(/\/$/, '');
  return `${trimmed}${path.startsWith('/') ? path : `/${path}`}`;
}

export function buildOpenAIHeaders({
  apiKey,
  includeContentType,
  extra,
}: {
  apiKey?: string | null;
  includeContentType: boolean;
  extra?: Record<string, string | undefined>;
}): Record<string, string> {
  const headers: Record<string, string> = {};
  if (apiKey?.trim()) headers.Authorization = `Bearer ${apiKey.trim()}`;
  if (includeContentType) headers['Content-Type'] = 'application/json';
  for (const [key, value] of Object.entries(extra ?? {})) {
    if (value) headers[key] = value;
  }
  return headers;
}

export function mapQueryInputToOpenAIChatBody(input: QueryInput): OpenAIChatBody {
  if (!input.model) {
    throw new AskSageError(null, 'OpenAI-compatible providers require an explicit model id.');
  }
  const messages: OpenAIChatMessage[] = [];
  if (input.system_prompt) messages.push({ role: 'system', content: input.system_prompt });
  if (typeof input.message === 'string') {
    messages.push({ role: 'user', content: input.message });
  } else {
    for (const turn of input.message) {
      const role: OpenAIChatMessage['role'] =
        turn.user === 'gpt' ? 'assistant' : turn.user === 'tool' ? 'tool' : 'user';
      const msg: OpenAIChatMessage = { role, content: turn.message };
      if (turn.tool_calls) msg.tool_calls = turn.tool_calls;
      if (turn.tool_call_id) msg.tool_call_id = turn.tool_call_id;
      if (turn.name) msg.name = turn.name;
      messages.push(msg);
    }
  }
  const body: OpenAIChatBody = { model: input.model, messages };
  if (typeof input.temperature === 'number') body.temperature = input.temperature;
  if (input.tools?.length) body.tools = input.tools;
  if (input.tool_choice) body.tool_choice = input.tool_choice;
  return body;
}

export function mapOpenAIResponseToQueryResponse(r: OpenAIChatCompletionResponse): QueryResponse {
  const first = r.choices?.[0]?.message;
  const usage: QueryUsage | null = r.usage
    ? {
        prompt_tokens: r.usage.prompt_tokens,
        completion_tokens: r.usage.completion_tokens,
        total_tokens: r.usage.total_tokens,
      }
    : null;
  return {
    message: first?.content ?? '',
    response: 'OK',
    status: 200,
    uuid: r.id,
    references: '',
    embedding_down: false,
    vectors_down: false,
    usage,
    tool_calls: first?.tool_calls,
  };
}

export function stripCodeFence(text: string): string {
  const fenced = text.match(/^```(?:json)?\s*\n([\s\S]*?)\n```\s*$/i);
  return fenced ? fenced[1]!.trim() : text.trim();
}

export function parseJsonFromOpenAIText<T>(text: string): T {
  return JSON.parse(stripCodeFence(text)) as T;
}

export function mapModelRowToModelInfo(row: OpenAIModelRow, fallbackOwner: string): ModelInfo {
  const vendor = row.id.includes('/') ? row.id.split('/')[0] ?? fallbackOwner : fallbackOwner;
  const out: ModelInfo = {
    id: row.id,
    name: row.name ?? row.id,
    object: 'model',
    owned_by: vendor,
    created: row.created === undefined ? 'na' : String(row.created),
  };
  const caps = extractCapabilities(row);
  if (caps) out.capabilities = caps;
  return out;
}

export function extractCapabilities(row: OpenAIModelRow): ModelCapabilities | null {
  const out: ModelCapabilities = {};
  if (typeof row.context_length === 'number' && row.context_length > 0) {
    out.context_length = row.context_length;
  }
  if (row.architecture?.input_modalities?.length) {
    out.input_modalities = row.architecture.input_modalities.slice();
  }
  if (row.architecture?.output_modalities?.length) {
    out.output_modalities = row.architecture.output_modalities.slice();
  }
  if (row.supported_parameters?.length) {
    out.supported_parameters = row.supported_parameters.slice();
  }
  return Object.keys(out).length > 0 ? out : null;
}

export function sortOpenAIEmbeddings(data: OpenAIEmbeddingsResponse['data']): number[][] {
  return [...data].sort((a, b) => a.index - b.index).map((d) => d.embedding);
}
```

```ts
import { AskSageError } from '../asksage/types';
import type { ModelInfo, QueryInput, QueryResponse } from '../asksage/types';
import { writeAuditEntry } from '../asksage/audit';
import type { LLMClient, ProviderCapabilities } from './types';
import {
  buildOpenAIHeaders,
  mapModelRowToModelInfo,
  mapOpenAIResponseToQueryResponse,
  mapQueryInputToOpenAIChatBody,
  parseJsonFromOpenAIText,
  sortOpenAIEmbeddings,
  urlForOpenAIPath,
  type OpenAIChatCompletionResponse,
  type OpenAIEmbeddingsResponse,
  type OpenAIModelRow,
} from './openai_compat';

const defaultFetch: typeof fetch = (input, init) => globalThis.fetch(input, init);
const DEFAULT_TIMEOUT_MS = 5 * 60 * 1000;
const DEFAULT_EMBEDDING_MODEL = 'nomic-embed-text';

export const LOCAL_OPENAI_PRESETS = [
  { id: 'ollama', label: 'Ollama', baseUrl: 'http://localhost:11434/v1' },
  { id: 'llamacpp', label: 'llama.cpp', baseUrl: 'http://localhost:8080/v1' },
  { id: 'lmstudio', label: 'LM Studio', baseUrl: 'http://localhost:1234/v1' },
] as const;

export interface LocalEndpointProbeResult {
  baseUrl: string;
  model: string | null;
  checkedAt: string;
  modelsOk: boolean;
  chatOk: boolean;
  toolCallsOk: boolean;
  jsonOk: boolean;
  embeddingsOk: boolean;
  warnings: string[];
  error: string | null;
}

export class LocalOpenAIClient implements LLMClient {
  readonly capabilities: ProviderCapabilities = {
    fileUpload: false,
    dataset: false,
    liveSearch: false,
    tools: true,
    jsonOutput: true,
    embeddings: false,
  };

  constructor(
    private readonly baseUrl: string,
    private readonly apiKey: string = '',
    private readonly fetchImpl: typeof fetch = defaultFetch,
    private readonly timeoutMs: number = DEFAULT_TIMEOUT_MS,
  ) {
    if (!baseUrl) throw new Error('LocalOpenAIClient: baseUrl is required');
  }

  async getModels(): Promise<ModelInfo[]> {
    const text = await this.requestText('GET', '/models', undefined);
    const parsed = JSON.parse(text) as { data?: OpenAIModelRow[] };
    return (parsed.data ?? []).map((row) => enrichLocalModelInfo(mapModelRowToModelInfo(row, 'local')));
  }

  async query(input: QueryInput): Promise<QueryResponse> {
    const body = mapQueryInputToOpenAIChatBody(input);
    const text = await this.requestText('POST', '/chat/completions', body, input.model);
    const parsed = JSON.parse(text) as OpenAIChatCompletionResponse;
    return mapOpenAIResponseToQueryResponse(parsed);
  }

  async queryJson<T>(input: QueryInput): Promise<{ data: T; raw: QueryResponse }> {
    const response = await this.query(input);
    const text = (response.message ?? '').trim();
    try {
      return { data: parseJsonFromOpenAIText<T>(text), raw: response };
    } catch (e) {
      const reason = e instanceof Error ? e.message : String(e);
      throw new AskSageError(
        response.status ?? null,
        `Local OpenAI queryJson: response was not parseable JSON (${reason}). Raw response (first 2000 chars):\n${text.slice(0, 2000)}`,
        text,
      );
    }
  }

  async embed(texts: string[], model: string = DEFAULT_EMBEDDING_MODEL): Promise<{ embeddings: number[][]; tokens: number }> {
    const text = await this.requestText('POST', '/embeddings', { model, input: texts }, model);
    const parsed = JSON.parse(text) as OpenAIEmbeddingsResponse;
    return {
      embeddings: sortOpenAIEmbeddings(parsed.data ?? []),
      tokens: parsed.usage?.prompt_tokens ?? 0,
    };
  }

  private async requestText(method: 'GET' | 'POST', path: string, body: unknown, model?: string): Promise<string> {
    const url = urlForOpenAIPath(this.baseUrl, path);
    const startedAt = Date.now();
    const hasBody = method === 'POST';
    const bodyText = hasBody ? JSON.stringify(body ?? {}) : undefined;
    let res: Response;
    try {
      const ac = new AbortController();
      const timer = setTimeout(() => ac.abort(), this.timeoutMs);
      res = await this.fetchImpl(url, {
        method,
        headers: buildOpenAIHeaders({ apiKey: this.apiKey, includeContentType: hasBody }),
        body: bodyText,
        signal: ac.signal,
      });
      clearTimeout(timer);
    } catch (err) {
      const message = err instanceof Error ? err.message : String(err);
      const errorMsg =
        `Network error calling Local OpenAI ${method} ${url}: ${message}. ` +
        `Check that the local server is running, the URL includes /v1, and CORS allows browser requests.`;
      void writeAuditEntry({
        endpoint: `/local-openai${path}`,
        model,
        prompt_excerpt: bodyText ?? '',
        response_excerpt: '',
        ms: Date.now() - startedAt,
        ok: false,
        error: errorMsg,
      });
      throw new AskSageError(null, errorMsg);
    }
    const text = await res.text();
    void writeAuditEntry({
      endpoint: `/local-openai${path}`,
      model,
      prompt_excerpt: bodyText ?? '',
      response_excerpt: text.slice(0, 1500),
      ms: Date.now() - startedAt,
      ok: res.ok,
      error: res.ok ? undefined : `${res.status} ${res.statusText}`,
    });
    if (!res.ok) {
      throw new AskSageError(res.status, `Local OpenAI ${method} ${url} failed (${res.status} ${res.statusText}): ${text || '(empty body)'}`, text);
    }
    return text;
  }
}
```

```ts
export function enrichLocalModelInfo(model: ModelInfo): ModelInfo {
  const key = model.id.toLowerCase();
  const preset = LOCAL_MODEL_PRESETS[key] ?? Object.entries(LOCAL_MODEL_PRESETS).find(([id]) => key.includes(id))?.[1];
  if (!preset) return model;
  return {
    ...model,
    capabilities: {
      ...(model.capabilities ?? {}),
      ...preset,
      input_modalities: model.capabilities?.input_modalities ?? ['text'],
      output_modalities: model.capabilities?.output_modalities ?? ['text'],
    },
  };
}

export function isLocalhostBaseUrl(baseUrl: string): boolean {
  try {
    const host = new URL(baseUrl).hostname.toLowerCase();
    return host === 'localhost' || host === '127.0.0.1' || host === '::1' || host === '[::1]';
  } catch {
    return false;
  }
}

export async function probeLocalOpenAIEndpoint({
  baseUrl,
  apiKey,
  model,
  fetchImpl = defaultFetch,
}: {
  baseUrl: string;
  apiKey: string;
  model?: string | null;
  fetchImpl?: typeof fetch;
}): Promise<LocalEndpointProbeResult> {
  const client = new LocalOpenAIClient(baseUrl, apiKey, fetchImpl);
  const warnings: string[] = [];
  if (!isLocalhostBaseUrl(baseUrl)) warnings.push('This endpoint is not localhost; prompts may leave this workstation.');
  const result: LocalEndpointProbeResult = {
    baseUrl,
    model: model ?? null,
    checkedAt: new Date().toISOString(),
    modelsOk: false,
    chatOk: false,
    toolCallsOk: false,
    jsonOk: false,
    embeddingsOk: false,
    warnings,
    error: null,
  };
  try {
    const models = await client.getModels();
    result.modelsOk = true;
    const selected = model || models[0]?.id || null;
    result.model = selected;
    if (!selected) {
      result.error = 'No local models were returned by /v1/models.';
      return result;
    }
    await client.query({ model: selected, message: 'Reply with exactly: pong', temperature: 0 });
    result.chatOk = true;
    const toolResponse = await client.query({
      model: selected,
      message: 'Call lookup_policy for document type PWS.',
      temperature: 0,
      tools: [{
        type: 'function',
        function: {
          name: 'lookup_policy',
          parameters: {
            type: 'object',
            properties: { document_type: { type: 'string' } },
            required: ['document_type'],
          },
        },
      }],
      tool_choice: 'auto',
    });
    result.toolCallsOk = (toolResponse.tool_calls ?? []).some((call) => call.function.name === 'lookup_policy');
    if (!result.toolCallsOk) warnings.push('Tool calls were not returned in native OpenAI format.');
    await client.queryJson<{ ok: boolean }>({ model: selected, message: 'Return strict JSON: {"ok":true}', temperature: 0 });
    result.jsonOk = true;
    try {
      await client.embed(['probe']);
      result.embeddingsOk = true;
    } catch {
      warnings.push('Embeddings endpoint is unavailable or not configured.');
    }
  } catch (err) {
    result.error = err instanceof Error ? err.message : String(err);
  }
  return result;
}
```

```ts
export function formatModelCapabilitySummary(m: ModelInfo): string {
  const caps = m.capabilities;
  if (!caps) {
    return 'Capabilities unknown; this provider did not return context window or modality metadata.';
  }
  const parts: string[] = [];
  if (caps.context_length) parts.push(`${formatCompactTokens(caps.context_length)} context`);
  if (caps.input_modalities?.length) parts.push(`input: ${caps.input_modalities.join(', ')}`);
  if (caps.output_modalities?.length) parts.push(`output: ${caps.output_modalities.join(', ')}`);
  if (caps.supported_parameters?.length) parts.push(`supports: ${caps.supported_parameters.join(', ')}`);
  if (caps.tool_calling === true) parts.push('tools: native');
  if (caps.tool_calling === false) parts.push('tools: not verified');
  if (caps.json_output === true) parts.push('JSON: verified');
  if (caps.recommended_vram_gb) parts.push(`recommended VRAM: ${caps.recommended_vram_gb} GB`);
  if (caps.backend_notes) parts.push(caps.backend_notes);
  if ((caps.context_length ?? 0) >= 128000 && caps.recommended_vram_gb) {
    parts.push('full context depends on backend settings and KV cache memory');
  }
  return parts.length > 0 ? parts.join(' · ') : 'Capability metadata returned, but no specific limits were listed.';
}
```

```md
# Local LLM Setup

This app can connect to user-managed OpenAI-compatible `/v1` endpoints. It does not install, start, stop, or certify local model servers.

## Supported Endpoint Shapes

- Ollama: `http://localhost:11434/v1`
- llama.cpp server: `http://localhost:8080/v1`
- LM Studio: `http://localhost:1234/v1`
- Custom OpenAI-compatible endpoint: any URL ending at the provider's `/v1` base

Most local endpoints do not require an API key. If your endpoint is protected, enter the key and the app will send `Authorization: Bearer <key>`.

## CUI And Privacy

Ask Sage remains the only provider in this app labeled for DHA health.mil tenant work. Local OpenAI endpoints are non-CUI by default unless your organization has separately approved the workstation, model, backend, and data flow.

If the endpoint is not `localhost`, `127.0.0.1`, or `[::1]`, prompts may leave the workstation or cross the LAN.

## Recommended Models

| VRAM | Models | Notes |
| ---: | --- | --- |
| 8 GB | `qwen3:4b`, `qwen3:8b`, `llama3.1:8b`, `gemma3:4b` | Good for cleanup, schema edits, and smaller drafting runs. |
| 16 GB | `qwen3:14b`, `mistral-nemo`, `gemma3:12b` | Better balance for document drafting and review. |
| 24 GB | `mistral-small3.1:24b`, `qwen3:30b`, `qwen3:32b`, `gemma3:27b` | Higher quality local drafting and review. |

Advertised context windows are not the same as practical VRAM fit. Full 128K or 256K context can require lower quantization, smaller batch sizes, CPU offload, or KV cache tuning.

## Tool Calls

The app uses OpenAI-format tools internally:

- `tools`
- `tool_choice`
- assistant `tool_calls`
- tool result messages

Use the local endpoint check before relying on tool-based workflows. Some local backends can generate JSON-looking tool requests without returning native OpenAI `tool_calls`.

## Troubleshooting

- Endpoint not running: start Ollama, llama.cpp server, or LM Studio and retry.
- Wrong base URL: include `/v1` in the configured URL.
- CORS failure: enable browser CORS support in the local backend.
- Model missing: pull or load the model in the backend first.
- Tool probe failed: try a Qwen3 or Mistral model known to support tools and confirm the backend's chat template supports tool calling.
```
