# Draft Workspace Product Positioning

## Intended users

Primary users are professionals who create structured, source-grounded Word
documents and must review AI contributions before publication. Secondary users
include analysts, technical writers, proposal teams, and administrators who
configure approved cloud or local model endpoints.

The application is designed for static deployment, disconnected or restricted
workstations with approved local models, and browser access to approved remote
providers. Deployment alone does not authorize any data classification.

## Position

Draft Workspace is a provider-neutral document drafting workspace. It turns
templates, existing documents, instructions, and reference material into
reviewable Word drafts while keeping the user in control of every accepted
change.

The working brand should feel professional, trustworthy, document-oriented,
provider-neutral, and extensible. It must not imply Ask Sage affiliation,
universal CUI authorization, cloud-only operation, a chat-only workflow, or
automatic unreviewed authorship.
